# Mini NPU 시뮬레이터

## 결과 리포트

각 크기에서 필터 하나로 MAC 계산을 10회 반복한 뒤, 한 번 계산하는 데 걸린 평균 시간을 밀리초로 기록했다.

| 크기 | 필터 하나의 MAC 횟수 | 평균 시간(ms) |
|---|---:|---:|
| 3×3 | 9 | 0.001537 |
| 5×5 | 25 | 0.003138 |
| 13×13 | 169 | 0.016467 |
| 25×25 | 625 | 0.065033 |

`mac()`은 모든 행의 모든 칸에서 한 번씩 곱하고 더하므로, 한 변이 5칸에서 25칸으로 늘면 행과 열이 각각 5배가 되어 MAC 횟수는 25회에서 625회로 25배가 된다.

### 실패 사례 `size_5_1`

5×5 입력을 두 필터와 비교한 결과, Cross 점수는 `0.9`, X 점수는 `0.8999999999999999`였다.
컴퓨터는 일부 소수를 이진수로 정확히 표현할 수 없어서 곱하고 더하는 과정에서 작은 반올림 오차가 생길 수 있다.
이 사례에서 두 점수 차이의 절댓값은 약 `1.11 × 10⁻¹⁶`이다. 프로그램은 이런 작은 차이로 승패가 갈리지 않도록 과제의 허용오차 `1e-9`보다 차이가 작으면 동점(`UNDECIDED`)으로 판정한다.
데이터 파일의 예상 정답 `x`는 표준 라벨 `X`로 변환된다. 실제 판정 `UNDECIDED`와 예상 정답 `X`가 달라 이 사례는 `FAIL`로 집계됐다.
