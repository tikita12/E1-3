# Mini NPU 시뮬레이터

## 결과 리포트

각 크기에서 필터 하나로 MAC 계산을 10회 반복한 뒤, 한 번 계산하는 데 걸린 평균 시간을 밀리초로 기록했다.

| 크기 | 필터 하나의 MAC 횟수 | 평균 시간(ms) |
|---|---:|---:|
| 3×3 | 9 | 0.001537 |
| 5×5 | 25 | 0.003138 |
| 13×13 | 169 | 0.016467 |
| 25×25 | 625 | 0.065033 |

`mac()`은 모든 행의 모든 칸에서 한 번씩 곱하고 더하므로, 한 변이 5칸에서 25칸으로 늘면 행과 열이 각각 5배가 되어 MAC 횟수는 25회에서 625회로 25배가 된다.
