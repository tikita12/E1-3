Mini NPU 시뮬레이터

숫자 배열로 십자가와 X 구별하기

무엇을 만들고 무엇을 배울까?

입력 패턴 하나를 두 필터에 각각 대어 보고, 어느 필터의 점수가 높은지 판정한다.

계산과 판정

  • 같은 위치의 입력값과 필터값을 곱하고 누적한다.
  • 실수 점수의 차이가 작을 때 동점 기준을 적용한다.
  • 점수, 판정, 예상 정답을 대조해 실패 원인을 찾는다.

데이터와 성능

  • JSON 키에서 크기를 읽고 라벨 표기를 통일한다.
  • 배열 크기에 따른 MAC 횟수와 평균 시간을 비교한다.
  • CPU에서 측정한 결과로 NPU의 병렬 계산 원리를 설명한다.

MAC 연산이란

각 쌍의 곱을 더하기

두 쌍을 계산하면

2 × 4 = 8

3 × 5 = 15

8 + 15 = 23

이 과제에서는

입력 패턴과 필터의 같은 위치 숫자를 곱합니다.

곱한 값을 모두 더해 필터 점수를 만듭니다.

AI에서 MAC이 중요한 이유

신경망은 입력과 가중치를 곱하고 더하는 계산을 반복한다.

입력 × 가중치 → MAC 반복 → 신경망의 다음 층

왜 중요한가?

신경망은 많은 입력과 가중치를 처리하며 MAC을 반복합니다.

이 과제와 연결

작은 배열에서 MAC을 직접 계산하고, 크기가 커질 때 비용이 어떻게 늘어나는지 살펴봅니다.

같은 X가 왜 1점과 5점을 받을까?

같은 위치의 숫자끼리 곱한다. 이 예시에서는 두 숫자가 모두 1인 칸만 점수에 1을 더한다.

필터에서 0인 칸은 계산을 건너뛸 수 있다

곱하기 0은 점수에 더해지지 않으므로, 0이 아닌 칸만 곱하면 된다.

큰 데이터에서 고려할 순서

  1. 0이 아닌 칸만 계산
  2. 메모리에 크면 패턴을 하나씩 읽기
  3. 필터가 많으면 입력을 묶어 재사용

이 과제의 현재 코드는 625칸을 모두 순회한다. 49번 계산은 적용 가능한 최적화 아이디어다.

같은 MAC을 어디에서 계산할까?

CPU 시간은 이 프로젝트에서 측정했다. NPU 쪽은 실행 구조로부터 예상한 병목이다.

CPU · 현재 Python 실행

  • 한 칸씩 읽어 하나의 점수에 누적
  • 작은 배열은 반복문 실행 비용
  • 큰 배열은 메모리 접근 비용

NPU · 병렬 실행을 가정

  • 여러 MAC 유닛이 부분합을 계산한 뒤 합산
  • 장치 전송과 메모리 대역폭이 병목 후보
  • 필터를 재사용하고 여러 입력을 묶어 처리 가능

6건을 판정해 무엇을 확인했나

원본 여섯 건의 예상 정답 일치율은 3/6, 즉 50%다.

정답과 일치한 3건

  • 점수 차이가 기준보다 커 높은 쪽을 선택
  • size_5_2 · size_13_1 · size_25_2

  • 유효한 입력에서 두 점수가 동점 범위에 들었음
  • size_5_1 · size_13_2 · size_25_1
